Here are some useful codes:


\wipe_one_file_on_sd_card.ino This code wipes a specific file from the sd card, the name of the file that should be deleted needs to be specified, then the code needs to be uploaded to the Arduino.

\wipe_whole_sd_card.ino This code can be used to wipe the entire sd card, it needs to be uploaded to the Arduino.
 
\take_data_updated.ino Use this code to take data with the Arduino, this code needs to be uploaded to the Arduino.

\data_reader_to_serial_monitor.ino With this code, you can read the data-files that are on the Arduino, this code needs to be uploaded to the Arduino.

\data_analysis.py This is a simple python script that can be used to analyze and plot the data. This does not get uploaded to the Arduino. You can use it on your computer like any other python code.
